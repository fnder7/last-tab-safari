Set up Last Tab

Three quick steps, and you’re ready.

  1. Turn on the extension

    In Safari Settings → Extensions, tick Last Tab.

    The extension is on.

    Safari doesn’t list Last Tab? Turn on Safari → Settings → Advanced → Show features for web developers, then Develop → Allow Unsigned Extensions.

  2. Allow it on every website

    Edit Websites… → For other websites: Allow. Needed for page previews.

    Allowed on every website.

  3. Open at login

    Keeps the shortcut working after a restart.

    Last Tab starts with your Mac.

Now in Safari press ⌥Q. Keep holding the modifier to pick a tab, release to switch.

Change the shortcut from the Last Tab button on Safari’s toolbar.
