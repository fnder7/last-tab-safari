# Cmd-Tab Style Tab Menu (TypeScript) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Move the extension to TypeScript with an esbuild bundle, then replace the command-based toggle with an in-page, horizontal, preview-card tab switcher: hold the modifier, tap the key to step through MRU-ordered tabs (Shift reverses), release to switch.

**Architecture:**
- Source lives in `src/` as typed ES modules, split into `background/`, `content/`, `options/` and `shared/`.
- `scripts/build.mjs` uses esbuild to bundle three IIFE entry points into `dist/` and copies the static files from `static/`.
- Xcode references only the fixed files in `dist/`, and a Run Script phase builds them first.
- Background: the MRU `order` list (`mru.ts`) and the preview cache (`previews.ts`) are pure modules; `controller.ts` answers typed messages.
- Content: shortcut matching (`shortcut.ts`) and a state machine (`menu-state.ts`) are pure; `menu-view.ts` is the only DOM file.

**Tech Stack:** TypeScript (strict), esbuild, Node 20 `node:test` run through `tsx`, `@types/webextension-polyfill` (types only), Manifest V3 Safari Web Extension, Xcode 26.6.

**Spec:** `docs/superpowers/specs/2026-11-06-tab-menu-design.md` (supersedes parts of `2026-11-06-last-tab-safari-extension-design.md`). The user also asked mid-planning to move to TypeScript for maintainability. That request is the source of Task 0.

## Global Constraints

- **Layout:** `src/background/*.ts`, `src/content/*.ts`, `src/options/index.ts`, `src/shared/*.ts`, `static/` (`manifest.json`, `options.html`, `images/`), `tests/*.test.ts`, `scripts/`. The build output goes to `dist/`, which is git-ignored, along with `node_modules/`.
- **Bundles:** `src/background/index.ts` → `dist/background.js`, `src/content/index.ts` → `dist/content.js`, `src/options/index.ts` → `dist/options.js`. Format `iife`, target `safari16`, no minification, sourcemaps off.
- **`browser` global:** typed via `src/shared/browser.d.ts` with `declare global { const browser: import('webextension-polyfill').Browser }`. Only the types are imported; the polyfill is never bundled.
- **Pure modules** (`mru`, `previews` cache, `shortcut`, `menu-state`) import nothing from `browser` and touch no DOM.
- **Message protocol** lives in `src/shared/messages.ts`:
  - `type Request = { type: 'menu:list' } | { type: 'menu:activate'; tabId: number }`
  - `type MenuTab = { id: number; title: string; favIconUrl: string | null; preview: string | null }`
  - `type ListResponse = { tabs: MenuTab[] }`
- **Storage keys** are constants in `src/shared/storage-keys.ts`: `MRU_STATE = 'mruState'` (`storage.session`) and `SHORTCUT = 'shortcut'` (`storage.local`).
- **Manifest (final):**
  - `permissions: ["tabs", "storage"]`, `host_permissions: ["<all_urls>"]`, no `commands`.
  - `background.scripts: ["background.js"]`.
  - `content_scripts: [{matches: ["<all_urls>"], js: ["content.js"], run_at: "document_start", all_frames: false}]`.
  - `options_ui.page: "options.html"`.
- **Default shortcut** is `{ modifier: 'alt', code: 'KeyQ' }`. Reverse is the same plus Shift. Match on `KeyboardEvent.code`.
- **Allowed codes:** `Key[A-Z]`, `Digit[0-9]`, `Backquote`, `Comma`, `Period`, `Slash`, `Semicolon`, `Quote`, `BracketLeft`, `BracketRight`, `Minus`, `Equal`.
- **Preview capture:**
  - `captureVisibleTab(windowId, {format: 'jpeg', quality: 60})`, downscaled to 400 px wide.
  - Captured 300 ms after activation or after `status: 'complete'`, and on `menu:list` with a 150 ms budget.
  - The cache holds at most 50 entries, in memory only.
- **Out of scope:** Ctrl+Tab, a Start Page fallback, iframes, cross-window switching, mouse selection, closing tabs from the menu, number jumps.
- **Commands:**
  - `npm test` = `tsc --noEmit && node --import tsx --test tests/*.test.ts`. Expect `# fail 0` and no tsc output.
  - `npm run build` = `node scripts/build.mjs`.
  - Build: `xcodebuild -project "Last Tab/Last Tab.xcodeproj" -scheme "Last Tab" -configuration Debug -derivedDataPath build build`. Expect `** BUILD SUCCEEDED **`.
  - Resources check: `ls "build/Build/Products/Debug/Last Tab.app/Contents/PlugIns/Last Tab Extension.appex/Contents/Resources/"`.

## Review Focus

1. **A non-Latin keyboard layout** (for example Russian, where `key` differs). Expected: the shortcut still matches by `code`. Test: Task 3 `matches by code regardless of key`.
2. **A tab title containing HTML.** Expected: it is shown as literal text. This is a requirement in Task 4 Step 1 (`textContent` only, no `innerHTML` with tab data), and Task 4's smoke check covers it manually.
3. **The selected tab is closed while the menu is open.** Expected: release does no harm, and the `menu:activate` rejection is swallowed. Test: Task 1 `activate ignores a closed tab`.
4. **Capture fails** (a restricted page, or a window mid-switch). Expected: the card has no preview and no unhandled rejection is raised. Test: Task 2 `capture failure leaves no preview`.
5. **Key auto-repeat while the key is held.** Expected: each repeat steps once and nothing is typed. Test: Task 3 `press while open steps forward and wraps`, and Task 4 Step 2 requires `preventDefault` on repeats.

### Task 3: Shortcut matching and menu state machine (pure)

**Files:**
- Create: `src/content/shortcut.ts`, `src/content/menu-state.ts`
- Test: `tests/shortcut.test.ts`, `tests/menu-state.test.ts`

**Interfaces:**
- Produces from `shortcut.ts`:
  - `type ModifierName = 'alt' | 'ctrl' | 'meta'`
  - `type Shortcut = { modifier: ModifierName; code: string }`
  - `type KeyLike = Pick<KeyboardEvent, 'code' | 'key' | 'altKey' | 'ctrlKey' | 'metaKey' | 'shiftKey'>`
  - `DEFAULT_SHORTCUT`
  - `MODIFIERS: Record<ModifierName, { prop: 'altKey' | 'ctrlKey' | 'metaKey'; key: 'Alt' | 'Control' | 'Meta'; symbol: string; name: string }>`, with ⌥ Option, ⌃ Control and ⌘ Command.
  - `isAllowedCode(code: string): boolean`
  - `isShortcut(value: unknown): value is Shortcut`: validates a stored value.
  - `matches(e: KeyLike, s: Shortcut): 'forward' | 'reverse' | null`. The code must be equal, the shortcut's modifier must be pressed, and the other two must not. `shiftKey` selects reverse.
  - `isModifierRelease(e: Pick<KeyboardEvent, 'key'>, s: Shortcut): boolean`
  - `label(s: Shortcut, opts?: { shift?: boolean }): string`, for example `'⌥ Option + Q'` or `'⌥ Option + ⇧ Shift + Q'`. The key text comes from the code: `KeyQ` → `Q`, `Digit1` → `1`, `Comma` → `,`.
- Produces from `menu-state.ts`:
  - `type MenuState = { phase: 'closed' } | { phase: 'loading'; steps: number; released: boolean } | { phase: 'open'; tabs: MenuTab[]; index: number }`
  - `type Action = { type: 'press'; dir: 'forward' | 'reverse' } | { type: 'listLoaded'; tabs: MenuTab[] } | { type: 'arrow'; dir: 'left' | 'right' } | { type: 'release' } | { type: 'escape' } | { type: 'blur' }`
  - `type Effect = { type: 'requestList' } | { type: 'render'; tabs: MenuTab[]; index: number } | { type: 'close' } | { type: 'activate'; tabId: number }`
  - `initial(): MenuState`
  - `reduce(state, action): { state: MenuState; effects: Effect[] }`
  - **Rules:**
    - **closed:** a press goes to `loading` with steps ±1, released false, and `[requestList]`.
    - **loading:**
      - A press adds ±1.
      - Release sets `released`.
      - Escape or blur → `closed` with no effects.
      - On `listLoaded`, with `n` = number of tabs:
        - if `n < 2` → `closed` with no effects;
        - otherwise `index = ((steps % n) + n) % n`;
        - if `released`, go to `closed` with `[activate]` when `index !== 0`, else `[]`;
        - otherwise go to `open` with `[render]`.
    - **open:**
      - press forward or arrow right → `index + 1 mod n`, `[render]`;
      - reverse or left → `index − 1 mod n`, `[render]`;
      - release → `closed` with `[close]`, plus `activate` when `index !== 0` (`close` first);
      - escape or blur → `closed` with `[close]`.
    - **Any action that doesn't apply** returns the same state object and `[]`.
